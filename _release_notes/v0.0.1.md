# napari-zenapi-streaming v0.0.1

Initial alpha release of the napari plugin and Python application for streaming
microscopy images from ZEISS ZEN Blue through the ZEN API.

## Highlights

- Three workflows: watch a ZEN-started experiment, start a selected experiment
  with live display, or stream directly to OME-Zarr without displaying frames.
- Latest-frame preview and per-channel scene mosaics assembled from streamed
  scene and tile coordinates.
- A shared configured OME-Zarr writer for the plugin, standalone CLI, and
  Python callers, with dedicated pixel subscriptions and bounded buffering.
- Automatic experiment startup through the API, or an armed writer that waits
  for manual startup in ZEN Blue.
- Experiment dimensions, Z spacing, and well positions from exported metadata,
  with positive live dimension counts taking precedence when available.
- HCS plate output when well metadata is valid, with generic multiposition
  fallback, tile merging, compression, and optional image pyramids.
- Raw 2D GRAY8/GRAY16 output with runtime pixel-type and payload validation.
- Acquisition completion reports; incomplete acquisitions retain partial data
  and report failure instead of opening the output as a successful result.
- User-owned configuration and logging, output-folder access checks before
  acquisition, and documented persistent output and experiment defaults.
- A Python example in `examples/stream_to_omezarr.py` with optional experiment
  selection and automatic startup. It disables overwriting existing output.
- Python 3.12-3.14 support and a PyQt6-based CI matrix on Windows, Linux,
  and macOS.

## Installation

Install compatible `zen_api` and `zen_api_utils` wheels first. These required
dependencies are not distributed on PyPI; wheel sources and version constraints
are documented in the repository README.

Then install the plugin and Qt binding in the same environment:

```powershell
python -m pip install napari-zenapi-streaming==0.0.1 "napari[pyqt6]" "PyQt6>=6.7,<6.10"
```

Live acquisition requires ZEN Blue, a configured ZEN API Gateway, a valid control
token, and the gateway certificate.

## Alpha Limitations

- ZEN Blue and its gateway run on Windows. Remote Linux clients are
  experimental and have not been qualified.
- OME-Zarr output accepts only 2D GRAY8 and GRAY16 frames, not color pixels.
- Display mode retains frames for final assembly and normalizes preview
  intensities. Use configured OME-Zarr output to retain raw quantitative data.
- The unconfigured standalone CLI mode buffers the acquisition in memory.
- Missing frames are not recovered from ZEN. Inspect `acquisition_status.json`
  before using any partial output.
- Automated tests use simulated responses and do not establish throughput or
  end-to-end frame completeness on real hardware.
