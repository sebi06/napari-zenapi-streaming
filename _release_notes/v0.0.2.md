# napari-zenapi-streaming v0.0.2

This alpha release preserves quantitative image intensities in Display mode,
adds lightweight stream-only viewing, and writes OME-Zarr 0.6 output.

## Highlights

- Preserve native GRAY8/GRAY16 pixel types and intensities through live
  display and final scene assembly, without independent per-tile stretching.
  Final mosaics use a channel-wide contrast range; live history updates no
  longer reset user-adjusted contrast.
- Add **Stream only (no history or mosaic)** to both Display workflows.
  It shows the latest arriving frame, supports channel filtering while
  streaming, retains no acquisition history, and leaves the final frame
  visible without saving a file or assembling an image.
- Make experiment controls scrollable in smaller plugin docks.
- Fix Display-mode pixel-type lookup using the nested ZEN API pixel-data
  field, with regression tests using real API message types.
- Finalize image metadata, collection/HCS containers, retained source tiles,
  and pyramids as OME-Zarr 0.6. Metadata conversion preserves pixel chunks
  and custom provenance and validates the new coordinate model.
- Open advertised collection image paths directly in napari, avoiding the
  missing-companion-XML reader crash and preserving channel-aware axes.

## Compatibility and upgrade notes

- Requires Python 3.12-3.14 and `ngff-zarr>=0.51.0`.
- Reading requires released OME-Zarr 0.6 or newer, as supported by the
  installed reader. Older and prerelease metadata are rejected with an
  explicit conversion message; existing stores are not migrated on opening.
- Generic scene mosaics remain in `scene_0`, `scene_1`, etc. image subgroups,
  even for a single scene. External viewers may require selecting a subgroup.
- The default Display workflow still retains frames for final mosaics.
  Enable stream-only viewing before acquisition to avoid that history.

## Installation

Install compatible `zen_api` and `zen_api_utils` wheels first; they are
required dependencies but are not distributed on PyPI. See the
[README installation instructions](../README.md#installation) for wheel
sources and version constraints.

Then install the plugin and Qt binding in the same environment:

```powershell
python -m pip install --upgrade "napari-zenapi-streaming==0.0.2" "napari[pyqt6]" "PyQt6>=6.7,<6.10"
```

Restart napari after upgrading.

## Validation and limitations

- Full local plugin regression suite: 119 tests passed, including simulated
  API responses, Qt offscreen tests, and OME-Zarr metadata/pixel-preservation
  tests.
- Automated tests do not establish live microscope throughput or end-to-end
  acquisition completeness.
- Live acquisition requires ZEN Blue and its configured API Gateway on
  Windows. Remote Linux clients remain experimental.
- Only 2D GRAY8/GRAY16 frames are supported; large retained acquisitions can
  exceed available RAM. Inspect `acquisition_status.json` before using any
  partial configured-writer output.
