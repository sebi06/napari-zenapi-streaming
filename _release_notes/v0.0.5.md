# napari-zenapi-streaming v0.0.5

This alpha maintenance release hardens Display-reader startup and shutdown
and updates ZEN dependency installation guidance.

## Changes since v0.0.4

- Abort acquisition startup if the pixel reader fails or closes before
  becoming ready, instead of waiting indefinitely.
- Propagate stream-close errors and retrieve failures from readers that have
  already exited. Shutdown still drains accepted frames and stops the frame
  processor when reader cleanup fails.
- Clarify response, task, and context-manager types, remove an unused viewer
  callback, and add focused lifecycle regression tests.
- Require `zen_api_utils>=0.2.0` and remove the plugin's `zen_api` upper bound.
  CI and installation examples now use the public `zen_api==2026.11.1` and
  `zen_api_utils==0.2.0` wheels.
- Add OME-Zarr and Zarr package-discovery keywords.

## Compatibility and upgrade notes

- Requires Python 3.12-3.14 and `ngff-zarr>=0.51.0`.
- Choose ZEN wheels compatible with your gateway. Installed utilities may
  impose their own API version bounds; removing the plugin's upper bound
  does not certify every gateway version.
- Acquisition workflows and native GRAY8/GRAY16 pixel handling are unchanged.
- New output remains OME-Zarr 0.6. Existing stores are not migrated or
  backfilled with channel colors.

## Installation

Install compatible `zen_api` and `zen_api_utils>=0.2.0` wheels first; they are
required dependencies but are not distributed on PyPI. See the
[README installation instructions](../README.md#installation) for the public
wheel URLs and gateway compatibility guidance.

Then upgrade the plugin in the same environment:

```powershell
python -m pip install --upgrade "napari-zenapi-streaming==0.0.5" "napari[pyqt6]" "PyQt6>=6.7,<6.10"
```

Restart napari after upgrading.

## Validation and limitations

- Full local regression suite: 148 tests passed. Ruff lint/format, focused
  mypy checks for the Display pipeline, source/wheel builds, and an
  installed-wheel configuration and plugin-discovery smoke test passed.
- CI covers Python 3.12-3.14 on Windows, Linux, and macOS.
- Automated tests use simulated gateway responses; they do not establish
  live microscope throughput or end-to-end acquisition completeness.
- Live acquisition requires ZEN Blue and its configured API Gateway on
  Windows. Remote Linux clients remain experimental.
- Only 2D GRAY8/GRAY16 frames are supported. Inspect
  `acquisition_status.json` before using partial configured-writer output.
- Existing third-party deprecation and Zarr acquisition-report warnings are
  not addressed by this release.
