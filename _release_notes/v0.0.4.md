# napari-zenapi-streaming v0.0.4

This alpha maintenance release preserves the selected ZEN experiment's
channel names and display colors in configured OME-Zarr output.

## Changes since v0.0.3

- Read active channel names and actual `#AARRGGBB` colors from the exported
  experiment XML for plugin and configured CLI acquisitions.
- Write per-image OMERO labels, `RRGGBB` colors, and display windows in the
  same order as channel subscriptions. Single-channel selections retain
  the selected source channel's metadata.
- Apply display metadata to generic scenes, HCS images, and retained source
  tiles, and preserve it when generating pyramid levels.
- Allow `napari-ome-zarr` to restore the saved experiment colors instead of
  relying on viewer-default colormaps.
- Warn on missing or invalid XML colors and use neutral grayscale rather
  than inferring a fluorophore color.

## Compatibility and upgrade notes

- Requires Python 3.12-3.14 and `ngff-zarr>=0.51.0`.
- New output remains OME-Zarr 0.6. Use a reader that supports 0.6 and OMERO
  channel display metadata.
- Existing output is not modified or backfilled with channel colors.
- Direct writer configurations without channel metadata retain the previous
  reader-default display behavior.
- This change affects display metadata, not acquired pixel intensities.

## Installation

Install compatible `zen_api` and `zen_api_utils` wheels first; they are
required dependencies but are not distributed on PyPI. See the
[README installation instructions](../README.md#installation) for wheel
sources and version constraints.

Then upgrade the plugin in the same environment:

```powershell
python -m pip install --upgrade "napari-zenapi-streaming==0.0.4" "napari[pyqt6]" "PyQt6>=6.7,<6.10"
```

Restart napari after upgrading.

## Validation and limitations

- Full local regression suite: 144 tests passed. Ruff lint and formatting
  checks passed, and both source and wheel distributions built successfully.
- Regression coverage includes active/inactive tracks and channels, color
  parsing and fallback, channel selection and ordering, UI metadata
  propagation, generic/HCS output, retained source tiles, and napari reader
  colors after pyramid generation.
- Automated tests do not establish live microscope throughput or
  end-to-end acquisition completeness.
- Live acquisition requires ZEN Blue and its configured API Gateway on
  Windows. Remote Linux clients remain experimental.
- Only 2D GRAY8/GRAY16 frames are supported. Inspect
  `acquisition_status.json` before using partial configured-writer output.
- The existing Zarr acquisition-report warning and NumPy/itkwasm
  deprecation warning are not addressed by this release.
