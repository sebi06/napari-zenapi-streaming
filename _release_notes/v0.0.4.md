# napari-zenapi-streaming v0.0.4

This alpha maintenance release fixes stream activation and shutdown so the
plugin listens only when its selected workflow requires it.

## Changes since v0.0.2

- Closing or removing the **Experiment Selector** dock closes its stream
  subscriptions and cancels owned background tasks, including a dedicated
  OME-ZARR writer. It does not stop the acquisition in ZEN or close napari.
  Reopen the plugin to establish a new connection.
- **Display: start selected experiment** stays unsubscribed until Start is
  clicked. The plugin loads the experiment, arms its experiment-ID filter,
  opens the reader, and only then triggers acquisition. It keeps receiving
  matching trailing frames before disconnecting after finalization.
- Changing the mode or channel filter does not arm an idle start-selected
  reader. Reader transitions are serialized to prevent duplicate
  subscriptions during repeated runs or overlapping lifecycle changes.
- **Display: watch ZEN experiment** continues to listen immediately for
  independently started experiments.

## Compatibility and upgrade notes

- Requires Python 3.12-3.14 and `ngff-zarr>=0.51.0`.
- Native GRAY8/GRAY16 Display pixels and stream-only viewing are preserved.
- New output remains OME-Zarr 0.6. Reading requires released format version
  0.6 or newer, as supported by the installed reader; older stores are not
  migrated automatically.
- Closing the plugin during OME-ZARR writing cancels that writer; do not
  treat interrupted output as a completed acquisition.

## Installation

Install compatible `zen_api` and `zen_api_utils` wheels first; they are
required dependencies but are not distributed on PyPI. See the
[README installation instructions](../README.md#installation) for wheel
sources and version constraints.

Then upgrade the plugin in the same environment:

```powershell
python -m pip install --upgrade "napari-zenapi-streaming==0.0.4" "napari[pyqt6]" "PyQt6>=6.7,<6.10"
```

Restart napari after upgrading.

## Validation and limitations

- Full local regression suite: 133 tests passed, including mocked stream
  lifecycles, real Qt dock closure/removal, embedded worker-loop shutdown,
  and OME-Zarr metadata and pixel-preservation tests.
- Automated tests do not establish live microscope throughput or
  end-to-end acquisition completeness.
- Live acquisition requires ZEN Blue and its configured API Gateway on
  Windows. Remote Linux clients remain experimental.
- Only 2D GRAY8/GRAY16 frames are supported; large retained acquisitions can
  exceed available RAM. Inspect `acquisition_status.json` before using any
  partial configured-writer output.
